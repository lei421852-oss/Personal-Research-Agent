# Stage 5.1.5：UI 功能审计

| 功能 | 本轮证据与边界 |
| --- | --- |
| 主工作台 | 浏览器读取首页和导航，HTTP 200；完整 JS console 未独立审计，不声称无任何前端错误 |
| 论文目录 | `/api/research/papers` 200；页面展示 25 条目录记录并区分正文与仅元数据；API 返回 ID、标题、可用性 |
| 论文独立详情、作者等 | 当前 `app/api/research_runs.py` 只有论文目录 GET，`app/workbench_web/app.js:renderPapers` 为非交互目录卡片；独立详情页面及详情 API 未实现，不能归因于服务故障。完整作者等元数据未由该目录 API 暴露 |
| 论文空/故障 | 源码有无论文兜底文案，服务无语料时返回 unavailable；本轮未注入语料故障，不声称真实空/错误页面通过 |
| Memory | 浏览器真实开发库列表、空有效状态、全部状态及一条详情/来源可见；`/api/memories` 200、非法 ID 404；未故障注入 |
| 历史任务 | 页面本机书签与服务端单任务状态/事件/报告可见；`GET /api/research/runs` 405，当前没有完整服务端历史列表路由，属于功能缺失，不是数据丢失证据 |
| 历史报告及引用 | 指定已完成任务的报告 200，浏览器可读历史回答、事件与论文证据；未进行新研究或人工语义审核 |

临时服务没有将按钮全部标成只读，但服务器拒绝非 GET/HEAD；不可据此开启正常研究。页面中的本机历史书签不是服务端全量列表。
