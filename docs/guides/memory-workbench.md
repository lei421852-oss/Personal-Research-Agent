# 记忆展示界面与只读 API

记忆按钮位于现有研究工作台。打开后使用同一页面的独立视图，返回时继续使用原有工作台会话与任务事件。界面仅展示服务端实际返回的数据，不提供手动编辑或删除。

## 使用前提

项目记忆默认禁用；启用需要已授权、已迁移的 PostgreSQL，以及 `AGENT_MEMORY_ENABLED=true` 和稳定的 `AGENT_MEMORY_PROJECT_ID`。数据库设置、迁移权限与来源规则见 [记忆模块架构](../architecture/agent-memory.md)。本阶段的临时测试库不等于当前用户开发库已迁移或启用。

首版以进程配置的 project scope 作为查询范围；客户端不能指定项目 ID。它没有用户登录、多用户身份认证或数据库行级安全，不应将工作台暴露给不受信任用户，也不能把项目范围过滤描述为完整的多租户权限系统。

## 只读接口

所有接口为 GET；返回的是历史用户声明，不是论文证据。source_ref 是原始用户问题的摘要标识，不能伪装为论文链接。

| 接口 | 用途 |
|---|---|
| `/api/memories` | 分页列表，支持 `query`、`memory_type`、`status`、`page` 和 `page_size` |
| `/api/memories/stats` | 当前项目的总数及 active、superseded、expired、deleted 数量 |
| `/api/memories/{memory_id}` | 记录详情，包括来源、版本、替代关系及时间 |

列表默认只返回 active；`status=all` 可以查看历史状态。到期但数据库状态仍为 active 的记录按当前时间呈现为 `effective_status=expired`。列表按更新时间降序、ID 升序排列，页大小 1–100；这不是跨请求快照，翻页期间若发生写入，记录位置可能变化。

未知或重复参数会被拒绝，非法 ID 或其他项目的记录返回 404。功能未启用或数据库不可用返回 503；空结果只表示查询成功但无匹配。统计与列表分开加载，某一区域失败时界面应保留其他可用区域并提供重试。

## 检验与限制

服务读取记忆经项目范围限定，显示的数据来自已有 PostgreSQL Repository。Agent 工具和原证据/引用约束没有改变。记忆软删除保留审计记录，因此历史视图不是物理删除保证。

离线 API 和浏览器测试不能替代实际部署验收；只有显式授权的隔离 PostgreSQL 才可运行真实数据库集成测试。不要为展示效果插入预设或虚构的记忆。
