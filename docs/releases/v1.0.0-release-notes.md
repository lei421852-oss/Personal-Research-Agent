# Multimodal Research Agent v1.0.0

发布日期：2026-10-11。工程版本由 `v1.0.0` Git 标签固化；冻结 `pyproject.toml` 的包元数据 0.1.0 保留，不代表已经提供完整 wheel 分发。

## 发布内容

- ReAct 主 Agent 根据用户自然语言问题与实际观察，选择直接回答、论文发现 / 查询扩展、文本 / Figure 工具或可选多 Agent 研究。
- 复用原 Planner、默认并发 Worker、引用验证、Reviewer、最多一轮 Recovery 与受限 Synthesis；F3.1 Coverage Worker 仍是可选实验。
- 严格单动作 Controller 与主策略有界纠正，不截取批次第一项；共享物理调用预算和真实执行指标。
- 中文答案优先工作台，线性工具轨迹 / 实际多 Agent 协作树、节点详情、取消及既有 G2/G2.1 历史回放。
- 正式中文 README、架构说明、新环境指南、分级演示与简历 / 面试材料。

本阶段没有更改生产 Agent、算法、语料、索引、模型或固定评测标签，没有重新训练或新增真实 Provider 研究。

## 发布验证

本轮完整 pytest 为 1265 passed，其中 12 项来自保留的本地未跟踪诊断测试，不进入远程代码分发。干净源码副本离线子集为 1251 passed、1 skipped、1 deselected；本地历史索引绑定项需要原资源。

Ruff、267 个 Python 文件格式、默认服务启动与正常关闭、真实浏览器交互、文档链接和敏感模式扫描均独立记录于[最终验收](final-acceptance-report.md)。Provider / Embedding 调用和索引重建均为 0。

Stage E 的根 README 经用户明确批准作为唯一文档例外，原 SHA 与历史标签可核验；其余 291 个冻结文件、原清单及 47 个受保护产物不变。原校验的 README 差异如实保留，由[发布专用校验](../../scripts/verify_release.py)分别核验，不覆盖历史指纹。

## 演示与研究保障

Demo A / B 使用已有真实主 Agent 记录，Demo B 实际发生多动作拒绝后恢复，最终两次检索回答，没有多 Agent。Demo C 的真实主 Agent 自主协作运行产物尚未保存，状态为待用户手动验收；Scripted 协作工具链与浏览器已验证，G2/G2.1 提供真实默认研究链回放。三者不互相冒充。

引用身份有效、Reviewer passed、自然语言比较正确和独立人工核验是不同层级。当前主要研究 Prepared PDF 文本 / 图注，不能把图片展示描述成全面像素级视觉推理。

## 已知限制

本地元数据发现与 5 篇受控正文语料；没有外部实时搜索、任意 PDF 自动解析、图像向量检索或完整人审 Benchmark。决策 / 停止 / 协议仍可能失败；研究预算不是成功承诺。进程内历史会在重启后丢失，取消同步请求需要清理。

模型、画像与向量索引不随 Git 分发；完整回归含历史资源绑定检查。新环境的画像生成结果可能不同，不以复制 24 个画像为目标。当前使用源码 checkout，完整 wheel 分发和依赖锁定留作后续工程工作。

原严格冻结检查脚本保留旧语义，某些历史演示入口在当前 README 文档例外下会拒绝原快照校验，应使用相应历史版本；当前默认工作台不依赖这些旧 CLI 的发布检查。
